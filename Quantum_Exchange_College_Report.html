1. Abstract

The Quantum Exchange is an enterprise-grade, high-performance stock market and trading simulation platform. It is engineered to replicate the immense data throughput, concurrency, and low-latency requirements of a live financial exchange. By employing a decoupled microservices architecture, the system isolates user-facing web traffic from the highly sensitive order-matching engine. 2. Introduction

Financial exchanges require high-throughput, low-latency systems capable of processing thousands of orders simultaneously without data races or integrity issues. The objective of this project was to develop a full-stack trading platform that simulates a live stock market. It includes real-time charting, order book management, limit and market order execution, and comprehensive user portfolio tracking. The project demonstrates advanced concepts in system architecture, including Publisher/Subscriber models, WebSockets, and in-memory data caching.

4. System Architecture & Flow

The architecture follows a microservices-inspired design, decoupling the user-facing APIs from the order execution engine. When an order is placed, it is pushed to a Redis queue rather than executed synchronously. A continuous background worker (the Order Engine) consumes this queue, utilizes Redis Sorted Sets (ZSET) to maintain time-price priority, matches buyers and sellers, calculates maker/taker fees, updates user portfolios in the SQL database, and triggers WebSocket notifications.

6. Error Handling & Race Conditions

6.1 The "Ghost Share" Mitigation

If the engine crashes while orders are sitting in the Redis Order Book, the user's shares remain "locked" in the SQLite database permanently. To fix this, an End-of-Day settlement script is executed upon a shutdown signal (CTRL+C).


def end_of_day_settlement():
    db = SessionLocal()
    # Refund Fiat
    users_with_locks = db.query(User).filter(User.locked_fiat > 0).all()
    for user in users_with_locks:
        user.fiat_balance += user.locked_fiat
        user.locked_fiat = 0
        
    # Release Locked Shares
    holdings_with_locks = db.query(Holding).filter(Holding.locked_qty > 0).all()
    for holding in holdings_with_locks:
        holding.locked_qty = 0
    db.commit()
